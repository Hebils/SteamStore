# Definición del problema

## Descripción del problema

Actualmente existen diferentes plataformas digitales para la compra y gestión de videojuegos. Para este proyecto se propone desarrollar una aplicación web que permita centralizar este proceso de manera organizada, ofreciendo a los usuarios un espacio donde puedan consultar videojuegos, conocer sus características y gestionar sus compras.

El proyecto busca solucionar la necesidad de contar con una plataforma web que permita a los usuarios registrarse, iniciar sesión, consultar un catálogo de videojuegos, revisar la información de cada juego, realizar compras simuladas y acceder posteriormente a los juegos adquiridos mediante una biblioteca personal.

Además, la aplicación debe gestionar información relacionada con los usuarios, videojuegos, compras y reseñas. También debe permitir el almacenamiento de archivos asociados a la plataforma, como imágenes, utilizando una solución de persistencia que combine una base de datos con almacenamiento de archivos.

## Objetivo general

Desarrollar una aplicación web Full-Stack para la gestión y compra simulada de videojuegos, permitiendo a los usuarios registrarse, autenticarse, consultar un catálogo, realizar compras y administrar una biblioteca de juegos adquiridos.

## Objetivos específicos

* Implementar un sistema de registro, inicio y cierre de sesión para los usuarios.
* Desarrollar un catálogo de videojuegos con información como nombre, descripción, género y precio.
* Permitir la consulta de información detallada de cada videojuego.
* Implementar un carrito de compras y un proceso de compra simulada.
* Crear una biblioteca donde los usuarios puedan consultar los videojuegos adquiridos.
* Permitir la creación y gestión de reseñas sobre los videojuegos.
* Implementar persistencia de datos mediante una base de datos.
* Implementar almacenamiento de archivos y guardar sus metadatos en la base de datos.
* Desarrollar una API REST para la comunicación entre el frontend y el backend.
* Implementar rutas públicas y protegidas de acuerdo con las necesidades de la aplicación.
