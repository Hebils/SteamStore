# Alcance del proyecto

## Alcance

Gamix será una aplicación web inspirada en las plataformas digitales de distribución de videojuegos. Su propósito será permitir que los usuarios consulten un catálogo de videojuegos y gestionen diferentes acciones relacionadas con la adquisición y organización de sus juegos.

El sistema contará con las siguientes funcionalidades principales:

### Funcionalidades incluidas

- Registro de nuevos usuarios.
- Inicio y cierre de sesión.
- Consulta del catálogo de videojuegos.
- Visualización de información detallada de cada videojuego.
- Carrito de compras.
- Compra simulada de videojuegos.
- Biblioteca personal con los juegos adquiridos.
- Consulta del historial de compras.
- Creación y gestión de reseñas de videojuegos.
- Gestión de información básica del perfil del usuario.
- Carga y almacenamiento de archivos asociados a los usuarios o videojuegos.
- Almacenamiento de los datos de la aplicación en una base de datos.
- Separación entre rutas públicas y rutas protegidas.
- Comunicación entre frontend y backend mediante una API REST.

### Historias de usuario

Una historia de usuario es una descripción corta y sencilla de una función de software contada desde la perspectiva de la persona que desea esa capacidad, generalmente el usuario final o cliente.

Las principales historias de usuario de Gamix son:

- **HU01:** Como usuario, quiero registrarme en Gamix para poder crear una cuenta y acceder a las funcionalidades privadas de la plataforma.
- **HU02:** Como usuario registrado, quiero iniciar sesión para poder acceder de forma segura a las funcionalidades privadas de mi cuenta.
- **HU03:** Como usuario autenticado, quiero cerrar sesión para finalizar de forma segura mi sesión en la plataforma.
- **HU04:** Como usuario, quiero consultar el catálogo de videojuegos para conocer los juegos disponibles en la plataforma.
- **HU05:** Como usuario, quiero consultar la información detallada de un videojuego para conocer sus características, género, descripción y precio.
- **HU06:** Como usuario, quiero agregar videojuegos al carrito para seleccionar los juegos que deseo adquirir.
- **HU07:** Como usuario, quiero consultar los videojuegos agregados al carrito para revisar mi selección antes de realizar una compra.
- **HU08:** Como usuario, quiero realizar una compra simulada para adquirir los videojuegos seleccionados.
- **HU09:** Como usuario, quiero consultar mi biblioteca para acceder a los videojuegos que he adquirido.
- **HU10:** Como usuario, quiero consultar mi historial de compras para revisar las compras realizadas anteriormente.
- **HU11:** Como usuario, quiero crear una reseña sobre un videojuego adquirido para compartir mi opinión sobre él.
- **HU12:** Como usuario, quiero gestionar mis reseñas para poder modificar o eliminar una reseña que haya creado.
- **HU13:** Como usuario, quiero gestionar la información básica de mi perfil para mantener mis datos actualizados.
- **HU14:** Como usuario, quiero cargar archivos asociados a mi perfil o a los videojuegos para almacenar los recursos permitidos por la plataforma.

## Fuera del alcance

Para mantener el proyecto dentro del tiempo y los recursos disponibles, las siguientes funcionalidades no serán implementadas:

- Procesamiento de pagos reales.
- Descarga real de videojuegos.
- Sistema de DRM o protección contra copias.
- Plataforma de juegos multijugador.
- Chat entre usuarios.
- Sistema de amigos.
- Sistema de logros.
- Lanzador de videojuegos.
- Integración con plataformas externas de videojuegos.
- Notificaciones en tiempo real.

## Usuarios del sistema

El sistema estará dirigido principalmente a personas interesadas en consultar y adquirir videojuegos de manera digital. Los usuarios registrados podrán acceder a las funcionalidades privadas de la plataforma, mientras que las personas no autenticadas podrán consultar las funcionalidades públicas disponibles.
